# setup, but nothing reads that file during a test run — so without this line the suite and
# `mypy` both fail on `import pyjfl` anywhere CI has not been primed by hand. Deliberately
# unpinned, unlike the manifest's exact pin: the manifest states what a *user* gets, while the
# tests should notice if a newer library breaks them before that version is ever pinned.
